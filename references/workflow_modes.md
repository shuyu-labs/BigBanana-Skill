# 工作流模式

| 模式 | 用途 | 是否调用远程 API |
|---|---|---|
| `plan` | 生成剧本和镜头/时长计划 | 可能调用文本模型 |
| `director direct` | 导演流水线：节拍→预算→分场景扩写→质检修订→质量报告 | 是（文本模型） |
| `run --approve` | 批量生成资产、首帧、视频和配音 | 是 |
| `quality assess` | 检查项目完整性和视觉质量 | 否 |
| `visual inspect/compare` | 检查或比较图片 | 否 |
| `visual grid/wardrobe` | 渲染九宫格或衣橱参考图 | 是 |
| `export` | 拼接视频、混入配音、生成字幕 | 仅本机 ffmpeg |
| `bigbanana_mcp.py` | 暴露项目规范化、检查和引用解析 | 否 |

`plan` 后必须人工审核成本和镜头数量；`director direct` 输出的质量报告三项覆盖未满 100% 时先修复再进关键帧阶段。`run` 必须带 `--approve`。远程任务超时先查询状态，不要直接重复提交。视觉检查失败时优先修复引用、首帧或提示词，再重新生成视频。
