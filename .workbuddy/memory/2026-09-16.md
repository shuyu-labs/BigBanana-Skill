## 2026-09-16 修复：剧本 JSON 缺 scene id 导致导演流水线校验全挂
- 现象：agent 生成的剧本 scenes 只有 name 没 id，导演流水线按 scene.id 校验对白/节拍归属必然失败（截图 S09 会话复现）
- 根因（双缺口）：① SCRIPT_PROMPT 输出模板本身就没有 id 字段（生成端无约束）；② bigbanana_director.py cmd_direct 直接 json.loads，
  不像 workflow 那样调 normalize_script 兜底
- 修复：① SCRIPT_PROMPT 模板给 characters/scenes/props/shots 补 id（char_01/scene_01/prop_01/shot_01），shots 改用 id 引用；
  ② director 入口加载后 normalize_script，若有补 ID 则写回 script.json 保持磁盘一致；
  ③ SKILL.md 标准流程第 1 步 + director 命令注释写明 id 约束
- 验证：11/11 离线测试过；normalize 模拟 name-only 剧本补 ID 且 scene_id 映射正确；SCRIPT_PROMPT format 渲染无花括号问题
- 注意：tests 需要 Pillow，托管裸 python 没有，用 envs/default venv 跑
